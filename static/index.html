Completed work

IMPLEMENTED IN THIS BUILD

Data and signal processing

Integrated the MAUS archive; extracted ECG, fingertip PPG, wrist PPG and GSR/EDA streams; incorporated derived inter-beat interval series; computed signal-quality and physiological feature summaries; aligned task, NASA-TLX, PSQI and response-log context.

Comparative evaluation

Built separate modality feature sets and a combined fusion feature set; evaluated binary task-demand classification with 22-fold Leave-One-Subject-Out validation; generated out-of-fold predictions, feature importance and a three-dimensional PCA cohort map.

This is a research software demonstrator, not a medical device. The N-back task label is a task-demand proxy. External cohort and hardware validation, real-time sensor acquisition and prospective intervention testing have not yet been completed.
